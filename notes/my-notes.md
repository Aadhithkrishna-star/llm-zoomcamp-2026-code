# Understanding the Groq LLM Client (LLM Zoomcamp)

This document explains every line of the Groq client code used throughout LLM Zoomcamp.

---

# Complete Code

```python
from dotenv import load_dotenv

load_dotenv()

from openai import OpenAI
import os

openai_client = OpenAI(
    api_key=os.getenv("GROQ_API_KEY"),
    base_url="https://api.groq.com/openai/v1"
)

print("Client created successfully!")

def llm(prompt):
    response = openai_client.chat.completions.create(
        model="llama-3.3-70b-versatile",
        messages=[
            {"role": "user", "content": prompt}
        ]
    )

    return response.choices[0].message.content

question = "I just discovered the course. Can I join now?"
answer = llm(question)
print(answer)
```

---

# Line-by-Line Explanation

## 1. Import `load_dotenv`

```python
from dotenv import load_dotenv
```

Imports the `load_dotenv()` function from the `python-dotenv` package.

Purpose:

* Read the `.env` file.
* Load environment variables into Python.

---

## 2. Load the `.env` file

```python
load_dotenv()
```

Reads the `.env` file located in the project folder.

Example:

```text
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxx
```

After executing this line, the API key becomes available through Python.

---

## 3. Import the OpenAI SDK

```python
from openai import OpenAI
```

Even though we're using **Groq**, we still use the **OpenAI Python SDK**.

Reason:

Groq provides an **OpenAI-compatible API**, so the same SDK works by simply changing the API endpoint.

---

## 4. Import the `os` module

```python
import os
```

The `os` module allows Python to interact with the operating system.

We'll use:

```python
os.getenv()
```

to read environment variables.

---

## 5. Create the Groq Client

```python
openai_client = OpenAI(
    api_key=os.getenv("GROQ_API_KEY"),
    base_url="https://api.groq.com/openai/v1"
)
```

This creates a client that communicates with Groq.

### `api_key`

```python
os.getenv("GROQ_API_KEY")
```

Reads the API key from the `.env` file.

Instead of hardcoding your API key into your program, it is stored securely inside `.env`.

---

### `base_url`

Normally the OpenAI SDK connects to:

```
https://api.openai.com
```

Changing the `base_url` tells the SDK to send every request to:

```
https://api.groq.com/openai/v1
```

This is why we can use Groq while still using the OpenAI SDK.

---

## 6. Print a Success Message

```python
print("Client created successfully!")
```

This simply confirms that the client was created successfully.

---

# Creating an LLM Function

```python
def llm(prompt):
```

Creates a reusable function.

Instead of writing the API request multiple times, we simply call:

```python
llm("Hello")
```

---

## Sending a Request

```python
response = openai_client.chat.completions.create(
```

Let's break it down.

### `openai_client`

The connection to Groq.

↓

### `.chat`

Use the Chat API.

↓

### `.completions`

Generate a chat completion.

↓

### `.create()`

Send the request to the model.

---

## Selecting the Model

```python
model="llama-3.3-70b-versatile"
```

This tells Groq which Large Language Model (LLM) should answer the question.

Examples:

* GPT-4.1
* GPT-4o
* Gemini
* Claude
* Llama 3.3 70B

Here we are using **Llama 3.3 70B**.

---

## Sending the Prompt

```python
messages=[
    {
        "role": "user",
        "content": prompt
    }
]
```

Chat models receive conversations instead of plain text.

Example:

```python
[
    {
        "role":"user",
        "content":"Explain Python"
    }
]
```

`role="user"` means the message comes from the user.

`content` contains the actual question.

---

## Receiving the Response

```python
response = ...
```

The complete API response contains much more than just the answer.

Example:

```
response
│
├── id
├── model
├── usage
├── choices
└── ...
```

---

## Extracting Only the Answer

```python
return response.choices[0].message.content
```

The actual response generated by the LLM is stored inside:

```
response
    ↓
choices
    ↓
0
    ↓
message
    ↓
content
```

This line returns only the generated text.

---

# Asking a Question

```python
question = "I just discovered the course. Can I join now?"
```

Stores the user's question in a variable.

---

# Calling the Function

```python
answer = llm(question)
```

The function:

1. Sends the prompt to Groq.
2. Waits for the model to generate a response.
3. Returns the generated answer.

The returned value is stored inside:

```python
answer
```

---

# Printing the Result

```python
print(answer)
```

Displays the AI-generated response.

---

# Overall Flow

```
Your Question
      │
      ▼
llm(prompt)
      │
      ▼
Groq Client
      │
      ▼
Groq API
      │
      ▼
Llama 3.3 70B
      │
      ▼
AI Generates Response
      │
      ▼
response.choices[0].message.content
      │
      ▼
answer

      ▼

```

---

# Key Takeaways

* `.env` stores sensitive information like API keys.
* `load_dotenv()` loads environment variables into Python.
* `OpenAI()` creates a client.
* `base_url` redirects the OpenAI SDK to Groq.
* `chat.completions.create()` sends a request to the LLM.
* `messages` represents the conversation.
* `response` contains the full API response.
* `response.choices[0].message.content` extracts only the generated text.
* Wrapping the API call inside a function makes the code reusable.
